# CSS Selectors Practice

A simple project demonstrating the use of basic CSS selectors in HTML. This project is created for practicing how different selectors target HTML elements and apply styles.

## Features

- Universal Selector (`*`)
- Element Selector (`p`)
- Class Selector (`.head`)
- ID Selector (`#bglime`)
- Descendant Selector (`p b`)
- Attribute Selector (`a[href*="..."]`)
- Pseudo-class Selector (`:nth-child()`)

## Technologies Used

- HTML5
- CSS3
