# Laundry Mart Website

## Description
Laundry Mart is a simple static website created using HTML. It provides information about laundry services, pricing, contact details, and includes a basic booking form.

## Features
- Welcome section
- Laundry service description
- Services list
- Price list table
- Book Now form
- Contact information

## Technologies Used
- HTML5

## Project Structure
```
Laundry-Mart/
│── index.html
│── README.md
```

Project is deployed using Github
