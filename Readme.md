# Task 4

A simple and responsive web page built using HTML and CSS. It displays an image with a stylish gradient button while following layout constraints using viewport units.

## Features

- Responsive layout using `vw` and `vh`
- Equal left and right spacing (25%)
- Top and bottom spacing (10%)
- Gradient styled button
- Uses `box-sizing: border-box`
- No Flexbox
- No absolute or relative positioning
- No page scrolling

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
Task-3/

```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
